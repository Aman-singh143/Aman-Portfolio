# Aman Singh Portfolio

A single-page professional portfolio for Aman Singh, focused on backend engineering, data platforms, and agentic AI systems.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Contents

- `index.html` - the portfolio site
- `assets/Aman_Singh_Resume.pdf` - downloadable resume used by the site

## Deployment

This is a static site and is ready for GitHub Pages. In the repository settings, set Pages to deploy from the `main` branch and the root directory.
