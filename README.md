## 🎯 About

A production-quality portfolio website built to showcase my experience as a **Python Backend Developer** at NJ Asset Management Pvt Ltd. Designed to impress recruiters and engineering managers with clean aesthetics, fast performance, and rich content.

**No frameworks. No dependencies. Pure HTML5 + CSS3 + Vanilla JS.**

## ⚡ Features

### 🎨 Design
- **Unique teal color palette** — stands out from generic blue portfolios
- **Aurora gradient animation** — slow-rotating conic gradient on profile card
- **Dark / Light mode** — with system preference detection + localStorage persistence
- **Page transitions** — CSS View Transitions API for smooth inter-page fades
- **Staggered animations** — cards cascade in with sequential delays
- **Scroll-reveal** — sections fade up as you scroll using IntersectionObserver
- **Typing effect** — rotating job titles with realistic type/delete animation
- **Custom scrollbar** — teal-tinted scrollbar matching the brand

### 📱 Responsive
- Fully responsive two-column → single-column layout
- Scrollable mini-nav on mobile
- Smooth mobile menu slide animation
- Optimized image sizing for small screens

### 🔍 SEO & Performance
- **53KB profile image** (compressed from 723KB — 93% reduction)
- Lazy loading + async decoding on images
- JSON-LD Person structured data for Google rich results
- Canonical links and Open Graph meta on all pages
- `<meta name="theme-color">` for mobile browser chrome tinting
- Font preconnect for faster loading
- Print-friendly styles

### ♿ Accessibility
- Skip-to-content link
- ARIA labels, roles, and `aria-current` on navigation
- `:focus-visible` outlines for keyboard navigation
- Semantic HTML5 structure
- WCAG AA color contrast compliance

## 📦 Deployment

This site is deployed on **GitHub Pages** from the `main` branch.

To deploy your own:
1. Fork this repo
2. Go to **Settings → Pages**
3. Set source to **Deploy from branch** → `main` / `/ (root)`
4. Your site will be live at `https://<username>.github.io/Aman-Portfolio/`
